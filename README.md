# Paulson J — Portfolio

A responsive single-page portfolio built with HTML, CSS, Bootstrap 5, and modern JavaScript.

## Run locally

Open `index.html` directly, or use the development server:

```powershell
npm install
npm run dev
```

## Production assets

Generate minified custom CSS and JavaScript:

```powershell
npm run build
```

The generated files are `css/style.min.css` and `js/custom.min.js`. The readable source files remain the defaults in `index.html` for straightforward maintenance.

## Validate the page

```powershell
npm run validate
```
