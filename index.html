ChapterWhen — Web Novels & Light Novels

ChapterWhen is a serialized literary platform for reading and publishing web novels and light novels. Engineered as a TypeScript Turborepo modular monolith with shared domain contracts across web and API workspaces, it pairs an accessible book-first reading experience with author publishing and worldbuilding tooling.

Architecture & Security

  • Next.js 16 (App Router, React 19, Tailwind CSS v4) web app deployed on Vercel alongside a NestJS 12 REST API (25+ domain modules) on Render.
  • PostgreSQL 18 on Neon accessed through Prisma 7 (@prisma/adapter-pg) with shared TypeScript types and validation schemas.
  • Argon2id password hashing, HttpOnly JWT cookie sessions, CSRF origin/header verification (X-Requested-With), server-side HTML prose sanitization, and route throttling.

Implemented Product Capabilities

  • Reader studio with Bookcloth, Folio, and Classic designs, five reading themes, Web Speech TTS, highlights, bookmarks, 3-level threaded comments, and offline PWA chapter sync.
  • Author Studio featuring Tiptap rich-text drafting, autosave, scheduled publishing, DOCX/PDF manuscript import into editable drafts, and privacy-safe readership analytics.
  • Novel Universe encyclopedia, timeline, and interactive @xyflow/react lore connection map protected by server-enforced three-tier spoiler redaction.
Next.js 16 React 19 TypeScript Tailwind CSS v4 NestJS 12 PostgreSQL 18 Prisma 7 Tiptap @xyflow/react PWA
